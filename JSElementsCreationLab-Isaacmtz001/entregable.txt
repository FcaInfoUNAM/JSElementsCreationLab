Describe en el archivo entregable.txt por qué hay contenido en el body al revisar en el navegador web pero en vs code no
no se mostrará en Visual Studio Code (VS Code) porque VS Code es un editor de código y no un navegador web. VS Code no tiene la capacidad de renderizar HTML y mostrarlo en una ventana de visualización como lo hace un navegador web.
Cuando se ejecuta el código HTML, CSS y JavaScript en un navegador web, el navegador interpreta el código y lo renderiza en la pantalla, mostrando el contenido en el body y aplicando los estilos definidos en las hojas de estilo CSS.
Por lo tanto, para ver el contenido del body y cómo se ve en el navegador web, es necesario abrir el archivo HTML en un navegador web

La tercera línea e.target.classList.add("btn-outline-danger"); agrega la clase CSS btn-outline-danger al botón, lo que hace que adquiera el estilo de color rojo asociado a esa clase.
La cuarta línea e.target.innerText= "Clicked" ; cambia el texto del botón a "Clicked", lo que indica al usuario que el botón ya ha sido presionado.
