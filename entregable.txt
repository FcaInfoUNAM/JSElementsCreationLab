PASO 2:

Función createCard:
Es recursiva, llamándose a sí misma dentro de la función buttonBtn.addEventListener. Cada vez que se invoca, incrementa el valor de la variable count y genera una nueva tarjeta.

Valor document:
El objeto document es una referencia global que representa el documento HTML actual. Permite acceder a los elementos del DOM, como el body, los divs, los botones, entre otros.

Función createElement:
Esta función crea un nuevo elemento DOM del tipo especificado. En el contexto dado, se emplea para generar divs, h5, botones, y otros elementos.

Función appendChild:
La función appendChild agrega un nuevo elemento hijo al final de un elemento padre. Aquí, se utiliza para añadir divs a otros divs, h5 a divs, botones a divs, etc.
