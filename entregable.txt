PASO 2

1. Función createCard:

Sí, la función createCard es recursiva. Se llama a sí misma dentro de la función buttonBtn.addEventListener. Cada vez que se llama a sí misma, aumenta el valor de la variable count y crea una nueva tarjeta.

2. Valor document:

El valor document es un objeto global que representa el documento HTML actual. Proporciona acceso a los elementos del DOM, como el body, los divs, los botones, etc.

3. Función createElement:

La función createElement crea un nuevo elemento DOM del tipo especificado. En este caso, se utiliza para crear divs, h5, botones, etc.

4. Función appendChild:

La función appendChild agrega un nuevo elemento hijo al final de un elemento padre. En este caso, se utiliza para agregar divs a divs, h5 a divs, botones a divs, etc.
